# Atividade: Sistema de Gestão de Reservas - Sweet Flight

Sua atividade será elaborar um algoritmo que permita aos atendentes realizarem a gestão de reservas de passagens para a companhia **Sweet Flight**. Este algoritmo deve solicitar a quantidade de aviões, bem como a respectiva quantidade de assentos disponíveis.

## 🛠️ Estrutura de Dados

Para armazenamento dos dados, utilize:
* **Dois vetores:**
    * Um vetor contendo **quatro posições**, onde cada posição representa um avião.
    * Outro vetor, também de **quatro posições**, que armazene a quantidade de assentos disponíveis.
* **Classe Python:** Utilize uma classe para armazenar os dados da reserva com os seguintes atributos:
    * `numero_aviao`
    * `nome_passageiro`

---

## 📋 Menu de Opções

Para facilitar o acesso e lançamento dos dados pelo atendente, elabore um menu conforme descrito abaixo:

1.  **Opção 1:** Registrar o número de cada avião.
2.  **Opção 2:** Registrar o quantitativo de assentos disponíveis em cada avião.
3.  **Opção 3:** Reservar passagem aérea.
4.  **Opção 4:** Realizar consulta por avião.
5.  **Opção 5:** Realizar consulta por passageiro.
6.  **Opção 6:** Encerrar.

---

## ⚙️ Diretrizes de Funcionamento

O algoritmo deve permitir a realização de **até 10 reservas**. Para cada uma, deverá ser solicitado o número do avião e o nome do passageiro.

### Regras por Opção:

* **Opção 1:** O atendente informa o número dos quatro aviões disponíveis.
* **Opção 2:** O atendente informa o número de assentos disponíveis para cada um dos aviões registrados na Opção 1.
* **Opção 3 (Reserva):**
    * Verificar se o avião informado existe. Se não existir: `“Este avião não existe!”`.
    * Verificar se há assentos disponíveis. Se não houver: `“Não há assentos disponíveis para este avião!”`.
    * Se validado, solicitar nome do passageiro, atualizar o quantitativo de assentos e exibir: `“Reserva realizada com sucesso!”`.
    * **Importante:** Respeitar o limite máximo de 10 reservas globais.
* **Opção 4 (Consulta por Avião):**
    * Informar o número do avião.
    * Validar existência do avião (se não existir: `“Este avião não existe!”`).
    * Exibir todas as reservas para este avião. Se vazio: `“Não há reservas realizadas para este avião!”`.
* **Opção 5 (Consulta por Passageiro):**
    * Informar o nome do passageiro.
    * Exibir todas as reservas vinculadas a este nome. Se vazio: `“Não há reservas realizadas para este passageiro!”`.
* **Opção 6:** Encerrar a execução do programa.
